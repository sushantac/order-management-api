# docs/not-asked/after-asking — The Packs You Asked For

These five packs started life in `docs/good-and-bad` retrospectives as gaps.
This folder is their home **as explicitly requested deliverables** ("consider
I asked for all these"). Each doc below is written as a requested artefact -
the *content* is canonical here; the parent `docs/not-asked/README.md` remains
the concept index.

| Pack (as requested) | Solves |
|---|---|
| [01-evidence-and-measurement-pack.md](01-evidence-and-measurement-pack.md) | "Prove the quality" - coverage, static analysis, load test, changelog, evidence index |
| [02-security-and-privacy-pack.md](02-security-and-privacy-pack.md) | "Show the security work" - STRIDE, DPIA-style data-flow, security review checklist |
| [03-architecture-and-onboarding-pack.md](03-architecture-and-onboarding-pack.md) | "Make it shareable" - C4 diagrams, as-built ADRs, repo navigation map |
| [04-operations-and-demo-pack.md](04-operations-and-demo-pack.md) | "Run & present it" - deploy/incident/rollback/backup runbooks + 10-min demo |
| [05-closure-execution-plan.md](05-closure-execution-plan.md) | "Execute everything" - the evidence-backed finish line |

## Requested-scope summary (as the requester framed it)
1. **Evidence & measurement** - numbers you can quote, not adjectives.
2. **Security & privacy** - threat model + DPIA-style document + checklist.
3. **Architecture & onboarding** - diagrams that render, ADRs, a tour.
4. **Operations & demo** - runbooks a real operator (or interviewer) can follow.
5. **Closure execution** - turn every "written but not run" artefact into proof.
