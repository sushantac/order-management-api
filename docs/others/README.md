# docs/others — Closing the "Expert Gap"

Your existing docs cover **reference knowledge** extremely well:
- `docs/learnings` — concepts in depth · `docs/design` — how it fits together ·
  `docs/business` — what it does · `docs/interview-cheat-sheets` — rapid recall ·
  `docs/good-and-bad` + `docs/next-time` — learning from mistakes.

What they do **not** yet cover is the layer that turns knowledge into **expertise**:
deliberate practice, self-measurement, retrieval, debugging pattern-recognition,
deep reading, and industry grounding. That is what this folder adds.

## Why these particular documents?

| Document | Closes which expert gap |
|---|---|
| [01-mastery-learning-path.md](01-mastery-learning-path.md) | No plan → "I read a lot but where am I?" A 12-week, week-by-week deliberate-practice programme |
| [02-self-assessment-rubric.md](02-self-assessment-rubric.md) | No measurement → you cannot improve what you do not score. A 4-level rubric per concept + tracking sheet |
| [03-flashcard-deck.md](03-flashcard-deck.md) | No retrieval → spaced repetition is the highest-yield study technique. An Anki-ready deck |
| [04-troubleshooting-playbook.md](04-troubleshooting-playbook.md) | Experts recognise symptoms fast. Symptom→cause→diagnosis→fix playbook for the issues that actually happen |
| [05-reading-list-and-resources.md](05-reading-list-and-resources.md) | Breadth beyond one repo. Books/docs/papers/certs mapped to each learning aspect |
| [06-practice-labs.md](06-practice-labs.md) | "Building ≠ understanding". Labs with acceptance criteria to rebuild core concepts from scratch |
| [07-industry-patterns-and-case-studies.md](07-industry-patterns-and-case-studies.md) | Grounding. Real companies/incidents that used each pattern - builds judgment and interview credibility |

## Suggested operating rhythm

1. **Weekly**: one lab from `06` (build) + one rubric section of `02` (measure).
2. **Daily (10 min)**: one `03` flashcard session.
3. **When something breaks**: check `04` first, then deep-dive in `docs/learnings`.
4. **Every 2 weeks**: re-read one industry case study in `07` and try to
   explain the design choices aloud.
5. **Before interviews**: `docs/interview-cheat-sheets` (recall) + a fresh `02`
   self-score to target weak spots.

## Honest note

These documents will only help if you *do* them. `01` tells you how little time
each week is enough; the value is in repetition and teaching-back, not in
reading faster.
